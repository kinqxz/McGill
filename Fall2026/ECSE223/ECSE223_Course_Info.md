## Topics / Learning Outcomes
- UML class diagrams (structural modelling)
- UML sequence diagrams & state machines (behavioural modelling)
- Behaviour-driven development, executable scenarios / acceptance tests
- Evaluating model quality & UML semantics
- Code generation from UML models
- Natural language constraints on class diagrams
- Design patterns
- Tools: IDEs, debugging, CI, version control, diff, issue tracking, refactoring, code review
