## Assessment Details
### Assignments
- 8 assignments, roughly weekly, done on mimi; delivered & submitted via **git**.
- Soft due date = the following week. **Hard due date** = the class test for that module (Module 1 → Oct 6, Module 2 → Nov 19).
- Only accepted once you see the final score line (e.g. `7/7`).

### In-class Quizzes
- 3 multiple-choice questions per lecture in Lectures 2–8 (Sep 3–Sep 24) and 12–20 (Oct 8–Nov 10) → 48 questions total.
- Need **20 correct** for 100%. Must be physically in class (bring phone/laptop) — answering remotely = cheating.

### Class Tests
- 1h15, during class time; location TBD (room assignment announced later). **Bring McGill ID.**
- Closed book; **one letter-size handwritten crib sheet** (single or double-sided, pen/pencil on paper — no tablet).
- Notify the instructor ASAP if there's a conflict.

### Final Exam
- 3 hours, in person, during exam period (Dec 7–22). Two evenly weighted sections (Part 1 + Part 2).
- Closed book; **two letter-size handwritten crib sheets**.
- No extra work available for unsatisfactory grades.

## Topics
- **Part 1 — Fundamentals of Linux:** file management, vim, hierarchical file systems, git, stdin/stdout/stderr, redirection, pipes, Bash scripting
- **Part 2 — C Programming:** compilation, syntax, call stack, debugging, datatype sizes, strings, pointers, dynamic memory, sequential & random-access files
- **Part 3 — Further topics**
