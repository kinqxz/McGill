## Software Systems

A **software system** is a set of interconnectd, communicating software artifacts, together with their specifications, configuration files, and documentation.

## Two modules

This course is split into two modules, first there is the **Fundamentals of Linux** and then there is **Programming in C**

At the end of module 1, you will be able to:
- Use the command-line on Linux to read, write, and manage files
- Compose atomic command-line programs into pipelines
- Write bash scripts to automate tasks relating to software development
- Use git to track modifications to bodies of source code

At the end of module 2, you will be able to:
- Write robust systems interactions in C
- Use appropriate algorithms and data structures in C
- Write and build large programs with multiple files efficiently
